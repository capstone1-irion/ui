빌드는 ECharts를 포함한 JS 번들 크기 알림을 출력하지만 성공합니다. Starlette의 httpx TestClient 사용에 대한 upstream deprecation 경고가 하나 있으며 테스트 실패는 아닙니다.

## 지연 표본

시험용 API를 처음 연결한 로컬 브라우저 세션에서 결과 수신→화면 반영 ACK p95 **45.2ms**, **3개 결과 표본**을 관측했습니다. 같은 확인 시점의 화면 전송→반영 ACK p95는 **19.49ms**, 339개 프레임 표본입니다.

두 지표는 브라우저의 React commit 후 requestAnimationFrame에서 보낸 확인을 서버가 수신한 왕복 상한값입니다. 실제 모델 추론 시간과 최대 500ms의 API 폴링 대기는 포함하지 않습니다. 미래 결과를 재생 시점까지 대기시키는 의도적 지연도 제외합니다. 작은 로컬 시험 표본이며, 운영 성능이나 모든 기기에서의 지연 보장이 아닙니다.

## 남은 외부 연동

실제 AI API·모델 성능 평가는 AI팀의 결과가 필요합니다. 커스텀 SITL 소스·공용 수집기를 확보하기 전에는 실시간 수신을 검증할 수 없습니다. 기본 PX4 빌드가 있다는 사실을 이 연결의 완료 근거로 사용하지 않았습니다.
