## PX4 SIH 확인

기존 빌드의 `sihsim_quadx`를 임시 디렉터리 `/private/tmp/arion-sih-v2-20261012`에서 instance 7로 실행했습니다. 기존 PX4 저장소·시뮬레이션 설정을 수정하지 않고 복사한 시작 파일에서 **14667→14560 전용 로컬 MAVLink 링크**를 만들었습니다. 검증 후 자체 인스턴스를 정상 종료했습니다.

검증 세션 `live-0d0b95dce3de4882`는 약 189초, 유효 관측 5193건을 기록했습니다. ATTITUDE·LOCAL_POSITION_NED·BATTERY_STATUS·HEARTBEAT·EXTENDED_SYS_STATE의 실제 PX4 메시지를 받았습니다. 다른 source 및 지원 밖 메시지는 제외 사유와 원문을 남겼습니다. 지상·비무장 상태의 수신 검증이며 실제 비행·실기체·커스텀 ESC 모델 시험이 아닙니다. 모터 텔레메트리는 없으므로 `—`로 표시했습니다.

통합 과정에서 uvloop의 UDP 대기 호환성 및 MAVLink 보조 필드의 bytearray 보존 문제를 찾아 수정하고 회귀 검사에 추가했습니다. 또한 기본 PX4가 내부 미지원 전류를 -100 raw로 내보내는 경로를 확인하여 `px4_sih_v1` 프로필과 선언적 sentinel 설정을 추가했습니다. 최초 SIH 수집의 `mavlink_common_v1` 표준 해석과 이 생산자 전용 해석을 구분합니다.

## 외부 검증과 운영 한계

실제 LSTM·Transformer 모델 코드·가중치·입력 계약은 인계 후 연결해야 합니다. 실제 시리얼 기기·실기체·커스텀 Gazebo 모터/배터리 모델은 검증하지 않았습니다. 클라우드 LLM 및 Jev 연동은 포함하지 않습니다. 디자인 전면 개편도 후속 시안 단계입니다.

활성 입력은 제한된 메모리 버퍼를 사용하지만 종료된 저널 재생은 현재 파일을 메모리에 읽습니다. 장시간 대용량 로그의 페이지 단위 재생은 후속 확장입니다. 서버는 단일 worker·로컬 사용자 환경을 기준으로 합니다.
