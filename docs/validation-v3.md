# 실시간 전처리 + NPZ 검증 — v0.4

검증일: 2026-10-12~13, macOS arm64 / Python 3.13 / 로컬 브라우저. 합성 전처리 입력과 명시적인 시험 API를 사용했습니다. 실제 LSTM·Transformer 정확도·실기체 비행 검증을 의미하지 않습니다.

## 자동 검증

백엔드 **68개**, 프런트엔드 **17개**, TypeScript/Vite 빌드를 통과했습니다. 백엔드는 실제 로컬 UDP 소켓과 가상 시리얼을 포함합니다. 신규 전처리·NPZ 테스트는 16개입니다.

- 물리값, 유효한 0, NaN 결측, invalid 값 보존, mask/status/정확한 age_ns/source_time_ns, 표시 매핑, 재생 일치.
- 5/10/20Hz 프로필, 특징·단위·전처리 버전 불일치, sequence 누락·공백·epoch 경계.
- 동일 재전송의 멱등 처리와 식별자 충돌 거부. 표시 버퍼 밖의 과거 재전송도 중복 저장하지 않음.
- 60초 구간 및 종료·epoch 마감, 저장 오류와 저널 기반 재시도, 비정상 종료·손상된 마지막 행 복구 및 원문 보존.
- 종료 전후 모델 구간 해시 동일, 전체 내보내기·NPZ 독립 재생, 재시작 뒤 파일 설정·결과 복원과 SQL 미사용.
- 잘못된 NPZ의 반복 가져오기 오류가 후속 요청을 막지 않고 임시 파일을 정리함. 업로드 원본 보존.
- SQLite 읽기 전용 이관·백업과 legacy 분류 보존.
- 화면 일시정지 중 수신 지속, 미래 결과 숨김, 외부 API에서 세션을 종료해도 WebSocket manifest가 재생 모드로 전환됨.
- 재접속 전 수신된 저장 결과 및 재생 커서보다 미래인 결과를 화면 반영 지연 표본에서 제외.

## 실제 자료와 브라우저

기존 데이터는 비행 2개, 세션 5개, 프로필 4개, 제공자 3개, 기존 판정 6개, v2 분석 353개, NPZ 검사 기록 1개를 이관했습니다. 기존 DB와 원본 JSONL은 변경하지 않았고 이관 marker와 SQLite 백업을 남겼습니다.

기준 JSONL은 SHA-256 `487299172cb2d519d062565f0ab0117ca5952d4e51b3b86a897ae4519309932e`, 유효 4,281건 / 제외 1건입니다. 손상된 321번째 행과 원본 보존이 유지됩니다.

브라우저에서 **실시간 연결 → 공용 수집기 / 전처리 스트림**으로 생성한 시험 세션에 공통 v1 프레임 1,201행을 전달했습니다. 600/600/1행의 구간 세 개로 저장했고 전체 내보내기와 구간 파일의 X/mask/status/age_ns/tick_ns/source_time_ns/sequence/epoch 배열이 모두 일치했습니다. 화면 일시정지 중에도 기록은 계속됐습니다. 두 시험 API의 서로 다른 판정과 동일 근거 구간 비교를 확인했습니다.

첨부 `real-training.npz`는 실제 브라우저 파일 선택으로 470행의 독립 비행으로 가져왔습니다. 메시지 그룹별 age를 특징으로 매핑하고 mask=false의 채움값을 실제 0으로 표시하지 않습니다. 원본 JSONL과 연결하지 않았으며 없는 위치·yaw를 만들어 3D에 표시하지 않습니다. 학습 실행 UI는 없습니다.

1280×800에서 NPZ 재생 3D·두 모델 비교의 하단은 678.9px, 고정 재생 바의 상단은 707px로 겹치지 않았습니다. 실시간 화면은 별도로 낮은 화면용 간격·제목 영역을 조정했습니다. 기본 레이아웃과 원본 로그 화면은 유지합니다. 390×844에서도 가로 넘침 없이 두 모델 카드를 표시했습니다.

## 지연과 범위

수정된 측정기의 새 10Hz 시험 세션에서 신규 결과 18개의 **결과 수신 → React commit 후 requestAnimationFrame 확인 왕복 p95는 118.67ms**, 화면 갱신 확인 왕복 p95는 19.82ms(306표본)였습니다. 목표 500ms를 만족했습니다. 3D 렌더 루프는 텔레메트리 갱신과 별도입니다.

측정은 AI 추론, API 확인 주기, 외부 전처리 및 NPZ 압축 시간을 제외합니다. 저장된 결과를 나중에 열거나 되감아 보는 대기 시간도 제외합니다. 근거 기록은 `.data/validation-v3-latency.json`, `.data/validation-v3-integration.json`에 있습니다. 실제 모델의 지연·정확도와 실기체 검증은 서비스 인계 후 별도로 수행해야 합니다.

기존 Starlette TestClient 사용 중단 예정 경고와 프런트엔드 큰 번들 경고는 남아 있습니다. 파일 가져오기는 압축 64MiB / NPZ 압축 해제 128MiB 이내이며, 전체 내보내기는 디스크 작업으로 수행합니다. 기존 원본 MAVLink JSONL 재생은 현재 메모리 파서를 유지하고, 완료된 전처리 기록은 NPZ 구간 캐시로 재생합니다.
