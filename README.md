# ui

배터리와 Motor 1~4의 상태 및 AI 이상 결과를 표시하는 별도 모니터링 UI 파트입니다.

## 최소 표시 항목

- 배터리와 각 모터의 현재 상태
- AI 정상/이상 판단
- 이상 발생 시간과 구간
- 이상 대상 부품

QGroundControl은 일반 비행상태 확인용이며, 이 UI는 프로젝트의 AI 결과 표시를 담당합니다. 사용자용 Health Score, RUL/SOH 예측과 고장 원인 진단은 필수 기능이 아닙니다.

## 디렉터리

| 경로 | 역할 |
| --- | --- |
| `src/` | 화면과 결과 수신 코드 |
| `assets/` | 화면용 정적 자산 |
| `tests/` | 화면·연동 검증 |

## 개발 기준

AI 판단은 `ai` 파트에서 수행합니다. UI는 결과를 표시하며 독자적으로 고장을 확정하지 않습니다. UI와 AI 간 전송 방식, 필드, 시간 기준은 `docs`의 인터페이스 명세에서 합의합니다. 임시/모의 데이터를 쓰면 화면과 문서에 명시하고, 실제 데이터 연동 이후 다시 검증합니다.

## 시작 상태

현재는 협업용 기본 구조만 있습니다. 웹/데스크톱 방식과 프레임워크를 아직 선정하지 않았으므로 `package.json`이나 특정 런타임을 임의로 추가하지 않았습니다. 실행 가능한 화면은 아직 없습니다.
